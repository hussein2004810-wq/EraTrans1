# KIUR — منصة اختبارات المجموعة الطبية

منصة عربية ثنائية اللغة (RTL) لإدارة اختبارات MCQ لكليات المجموعة الطبية في جامعات العراق، مبنية بـ **React + TypeScript + Vite + Tailwind CSS v4**.

## الميزات

### الطالب
- تسجيل حساب بتسلسل أكاديمي: الجامعة ← الكلية ← القسم ← المرحلة (19 جامعة عراقية، 6 كليات، 40+ قسم)
- اختبارات بأنماط متعددة: اختيار من متعدد، صح/خطأ، أكمل الفراغ، وحالات سريرية بصور
- مؤقت، خريطة أسئلة، حفظ التقدم والاستكمال لاحقًا، مراجعة كاملة مع الشرح العلمي
- شهادة اجتياز PDF وتصدير النتائج، ومشاركة الاختبارات مع طلاب جامعات أخرى (بموافقة الإشراف)

### الإشراف — هرمية صلاحيات
- **مالك المنصة**: كل الصلاحيات، يرقّي المشرفين ويحدد نطاقاتهم وسجل التدقيق وسجل الحسابات
- **مشرف جامعة / رئيس قسم / مقرر / دكتور / أستاذ / مشرف منصة**: صلاحيات ونطاق رؤية يحدده المالك
- قاعدة خصوصية صارمة: مشرف جامعة لا يرى طلاب الجامعات الأخرى، ومشرف قسم لا يرى الأقسام المجاورة
- إنشاء وتعديل الاختبارات: نسبة النجاح، خصم الدرجات، عشوائية الأسئلة والاختيارات لكل محاولة
- بنك أسئلة + رفع Excel/Word + مكتبة صور سريرية + لمحات سريرية ينشرها المالك للطلبة
- تصدير درجات الطلاب Excel / Word، تقارير، سجل تدقيق كامل، وأداة اختبار ضغط (500 طالب افتراضي)

### الأمان أثناء الاختبار
ملء الشاشة، منع النسخ والقوائم، رصد مغادرات النافذة وتوثيقها، تشويش مُبذّر فريد لكل طالب.

## التشغيل المحلي
```bash
npm install
npm run dev      # تطوير
npm run build    # إنتاج → dist/
```

## النشر
راجع [GITHUB.md](./GITHUB.md) لرفع المشروع كمستودع خاص، و[DEPLOY.md](./DEPLOY.md) للنشر المجاني على Netlify / Vercel.

## المزامنة والمصادقة (Supabase)
- مزامنة البيانات بين الأجهزة عبر 11 جدولًا (`supabase/schema.sql`)
- **المرحلة الثانية منفّذة**: مصادقة عبر Supabase Auth (كلمات مرور مشفّرة bcrypt) + Hook حدّ المعدل
  (`supabase/migrations/20260103000000_password_rate_limit.sql`)
- تقييد اختياري لجداول البيانات على الموثّقين: `supabase/optional_authenticated_lockdown.sql`
- خطوات التشغيل الكاملة في `STEPS.md` والنشر في `DEPLOY.md`
